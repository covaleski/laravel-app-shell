# Laravel App Shell Utilities

This package provides middleware, views, and Blade directives to quickly build
an App Shell Architecture implementation on your application's front-end.

## Installation

Install this package using the Composer package manager:

```sh
composer require covaleski/laravel-app-shell-utils
```

To customize default assets, run the following command to publish them:

```sh
php artisan vendor:publish --tag=laravel-app-shell
```
